# Unraid Community Applications Template

This directory contains the Unraid CA XML template for the Puget Sound Marine Forecast container.

## Files

- `puget-sound-marine-forecast.xml` — Unraid CA template defining the container configuration
- `icon.png` — App icon (replace with a proper icon before publishing)

## Installation

See [DEPLOYMENT.md](../DEPLOYMENT.md) for full Unraid installation instructions.

## Publishing to Community Apps

1. Ensure Docker image is available at `ghcr.io/longman391/puget-sound-marine-forecast:latest`
2. Create an Unraid forum support thread
3. Update the `<Support>` URL in the XML template
4. Submit to the CA maintainers via the Unraid forums
